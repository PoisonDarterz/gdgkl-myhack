# Quick Task 31: Backend .venv Setup + requirements.txt

## Goal

Set up a Python virtual environment at `backend/.venv`, install all packages required by the backend, and generate `backend/requirements.txt`.

## Tasks

### Task 1: Create .venv and install dependencies

**Files:** `backend/.venv/` (new), `backend/requirements.txt` (new)

**Action:**
1. Create `.venv` inside `backend/` using `python3 -m venv .venv`
2. Install all required third-party packages into it:
   - `fastapi`
   - `uvicorn[standard]`
   - `python-dotenv`
   - `google-genai`
   - `supabase`
   - `requests`
   - `pydantic`
3. Generate `backend/requirements.txt` via `pip freeze`

**Verify:** `backend/requirements.txt` exists and contains all packages above.

**Done:** requirements.txt committed to repo.
