<task type="auto">
  <name>Task 1: Add noise overlay CSS class to globals.css and render overlay div in layout.tsx</name>
  <files>app/globals.css, app/layout.tsx</files>
  <action>
    In app/globals.css, add a `.noise-overlay` class inside `@layer base` (after the existing body/html rules):

    ```css
    .noise-overlay {
      position: fixed;
      inset: 0;
      background-image: url(/images/noise.png);
      background-repeat: repeat;
      background-size: auto;
      opacity: 0.3;
      pointer-events: none;
      z-index: 9999;
    }
    ```

    Use `position: fixed` with `inset: 0` so the overlay covers the entire viewport at all times — this makes it appear as a full-page grain regardless of scroll position. `pointer-events: none` ensures it never blocks clicks. `z-index: 9999` puts it above all content visually. Opacity 0.3 = exactly 30% per Figma spec.

    In app/layout.tsx, add a `<div className="noise-overlay" aria-hidden="true" />` as the FIRST child inside the `<div className="...font wrapper...">` element (the one with `courierPrime.variable`, `instrumentSerif.variable`, `workbench.variable` classes). The `aria-hidden="true"` attribute hides it from screen readers since it is purely decorative.

    The overlay div references `/images/noise.png` which the user will place at `public/images/noise.png`. The CSS `url(/images/noise.png)` works because Next.js serves `public/` at the URL root.

    Do NOT use `next/image` for this — CSS background-image is correct here because the noise texture is a repeating decorative pattern, not a content image, and `next/image` does not support CSS background usage.
  </action>
  <verify>Run `npm run build` — build must pass with no TypeScript or CSS errors. Also run `npm run lint` — no lint errors.</verify>
  <done>Build and lint both pass. The layout.tsx renders a `.noise-overlay` div as first child of the font wrapper. The globals.css contains the `.noise-overlay` class with position fixed, opacity 0.3, and pointer-events none.</done>
</task>
